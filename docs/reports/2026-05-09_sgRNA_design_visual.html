1.Overview — qué hace el script y por qué importa

El script pre-screen (no production-grade design). Identifica candidatos NGG PAM sites en early CDS y los rankea por heurísticas conocidas (GC content, polyT terminator, position rules). Reduce el espacio de búsqueda de ~40 sites a top 10, listos para validación con CRISPRdesign tools production que tienen off-target databases.

Por qué pre-resolve este item: sin gates humanos. Es 100% computacional. Permite tener la lista de candidatos lista para que el wet-lab partner valide vs production tools (CRISPRscan/CHOPCHOP/CRISPOR) tan pronto como se decida el strategic direction. Adelanta ~1 semana del timeline experimental.

5.Strand diversity y recomendación de selección

Una buena selección de 2-3 sgRNAs incluye:

  • Strand diversity: mix de sense + antisense para reducir orientation bias
  • Position diversity: sgRNAs separados ≥ 50 nt para evitar overlap target
  • Score consistency: todos en top 10 (score ≥ 70)

6.Workflow para wet-lab partner

Estos sgRNAs son candidatos pre-screen, no production. El wet-lab partner debe:

  1. Validar con production tools: ingresar las secuencias 23 nt completas (sgRNA 20 + PAM 3) en CRISPRscan (crisprscan.org), CHOPCHOP (chopchop.cbu.uib.no), y CRISPOR (crispor.tefor.net). Comparar scores. Validar off-target predictions con sus databases entrenadas en zebrafish genome.
  2. Seleccionar 2-3 finales del top 10 priorizando consenso entre los 3 tools, strand diversity, y off-target score bajo (production tools tienen full off-target prediction; el script no lo hizo).
  3. In vitro cleavage assay con cada sgRNA + Cas9 protein + PCR amplicon de hoxb8a antes de microinjection. Confirmar cleavage band en gel. Si un sgRNA falla, descartar y usar siguiente del top 10.
  4. Order como Alt-R sgRNA from IDT (zebrafish RNP injection standard). Cas9 protein + sgRNA RNP es más eficiente que Cas9 mRNA + sgRNA en zebrafish embryos.
  5. Microinjection 1-cell stage embryos con RNP. Evaluar editing efficiency con HRMA en pool de 10 embryones a 24 hpf — confirm >50% editing antes de proceder con full experiment.
  6. Si editing eficiency <30%: retroceder a paso 2 y elegir distinto sgRNA del top 10. Repetir.

7.Caveats y limitaciones del pre-screen

Importantes:
  • NO incluye análisis de off-targets. Off-target prediction requiere base de datos genoma-wide entrenada. Los production tools (CRISPRscan/CHOPCHOP/CRISPOR) hacen esto; este script no.
  • Scoring es heurístico. GC content, polyT, position rules. No reemplaza scoring de tools production que usan CNN entrenados (e.g., Doench score, Azimuth score).
  • Solo busca early CDS (primeros 300 nt). Para LoF allele esto es óptimo (early frameshift), pero excluye late-CDS sgRNAs que podrían ser útiles para domain-specific KO.
  • NGG PAM solo (SpCas9). Si se usan otros Cas variants (Cas12a, SpRY, etc.), el script no los soporta sin modificación.
  • No considera transcript variants. El script usa el canonical transcript. Si hay alternative splicing relevant, otras isoformas pueden no ser afectadas igualmente.

Para Phase I "prueba pequeño", esto es suficiente como input al wet-lab partner que validará con production tools antes de ordenar reagentes. La inversión de pre-screen ($0 cómputo) reduce el espacio de búsqueda de ~40 sites a top 10, ahorrando tiempo del partner sin sacrificar quality del final selection.
