**Date:** May 04, 2026 · **Bump:** v2.1 → v2.2 (minor, backwards-compatible)

## Why this bump exists

On April 30, 2026, the v2.1 architecture was stress-tested against 2025+ LLM reasoning evidence (Anthropic April 2025 on `framework_applied` self-report, Vega Feb 2025 on calibration difficulty, Mirzadeh and Roh on perturbation-resistant evaluation, plus ~22 other papers). The full evidence and reasoning live in [`stress-test-completo.md`](stress-test-completo.md) / `.pdf`. v2.2 is the operational consequence of that brief — recalibrations of thresholds, prioritization of frameworks, and clearer Method 1/2 guidance. **No structural changes** to the five tests, the dual-method architecture, or the biological POC.

### ADR-0001 correction note

The execution plan as drafted by the audit agent proposed ADR-0001 with wet-lab-style scenarios (A-hipo / B-control / C-rescue / D-orthogonal). The actual cascade-session decision (Mode A washout × Mode B persistent × hipo × KO) was confirmed in `causal-ablation-cascade-sim/SKILL.md` lines 51-61 before writing. ADR-0001 records the actual decision; the audit-proposed wet-lab evolution is forward-looking and would become a separate ADR if adopted for Phase II.

### Architectural decisions embedded

- Squidiff is structurally transcriptomic, not morphological — this limit is preserved as honesty in every output, not hidden. Morphology is the project's primary focus; Squidiff complements via Mode 3 cross-verdict with Morpheus.
- Mode 0 synthetic fallback retained but capped at 0.50 confidence to prevent it from being used as a substitute for Mode 1.
- PASS-DECOUPLE only emittable in Mode 3 (requires Morpheus signal) — protects against the skill inventing a paradigm verdict it cannot justify.
- Test 4 calibration loop closed via `substrate_calibration/` — Squidiff Mode 1/3 outputs automatically write claim records that include the seed for replayability.
- "Stop adding, start invoking" — Phase I HOLD prevents adding more capability until v2.2 adoption audit informs decisions.
- **Determinism is non-negotiable for any HUMAN GATE artifact.** Future skills generating figures must include seeded PRNG by construction. This is now a substrate-integrity rule on par with the honesty disclaimer.
